# Divyansh Mishra — Portfolio

A responsive React + Vite portfolio website for showcasing full-stack development work and freelance services.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
```

The production site is generated in `dist/`.

## Deploy

You can import this project into Vercel or Netlify. For Vercel, choose the Vite framework preset, use `npm run build` as the build command, and `dist` as the output directory.
